Alto Sax Transposer

Load a MusicXML melody and read back the written alto saxophone part. Transposition, key respelling, and engraving run entirely in your browser.

Alto saxophone is an E♭ instrument. A written note sounds a major sixth lower than concert pitch, so a concert-pitch part transposes up 9 semitones to become the written alto part (which adds 3 sharps to the key signature).

Input

Getting music in

Export MusicXML (.musicxml, .xml, or compressed .mxl) from MuseScore, Finale, Sibelius, or any notation app; .mxl is unpacked in the browser. For a scanned PDF, run Audiveris on your own machine first (desktop app, free), export its MusicXML, then load that here.

Transposition note

The shift is exact in pitch; enharmonic spelling of the written key is handled by the renderer and is worth a quick glance on first load. The alto's comfortable written range is about B♭3 to F6 use the octave control if a line runs off the staff.

If the staff does not render

This page loads one script from a CDN. For a fully offline, dependency-free copy, download opensheetmusicdisplay.min.js into the same folder and change the script tag to point at the local file.
