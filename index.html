Getting music by name or link

Search folk tunes queries thesession.org (traditional / folk only) and loads a result directly — transposed and playable like any input. For Vietnamese and other songs, Find on MuseScore and Find on web open a name search in a new tab; locate a score there, download its MusicXML / .mxl, then bring it back with Fetch link (any URL that allows cross-origin requests; raw GitHub links are dependable) or the file picker. No free, legal service returns copyrighted songs' notation automatically, so the tool helps you find a file rather than pretending it can fetch any song. The Vietnamese folk tune button loads a traditional, public-domain melody (Kìa Con Bướm Vàng) with lyrics as a ready example.

Source detection

On load, the tool reads the file's first part — its instrument name, General MIDI program, and any written-pitch transpose — and sets Source part is written for automatically (concert, B♭, F, or E♭). It also flags grand-staff piano files, where Melody only is the right choice. It is a best guess from the file's metadata; change the dropdown yourself and it stays on your choice.

Melody extraction

Melody only keeps the top staff of a piano or multi-staff score, drops the accompaniment and bass clef, reduces any chords to the top (melody) note, keeps the lyrics, and labels the part Alto Sax, which is what a single-line sax part should be. Switch to Full score to render the source untouched.

Playback

Playback uses recorded alto-sax samples (the MusyngKite soundfont), streamed the first time you press Play, so it sounds like a real horn rather than a synth. With no connection it falls back to a built-in synthesized tone. Concert plays what a real alto actually produces reading this part (the song's true pitch); Written sounds the noteheads at face value, a major sixth higher, for verifying what is on the page.

The note being played is highlighted on the staff as it sounds. Play toggles play/pause, Stop returns to the start, the seek bar scrubs anywhere, and clicking a note jumps playback to it. To drill a passage, press Set A and Set B at the two points (or drag the seek bar there first) and tick Loop A–B to repeat just that section.

Getting music in

Export MusicXML (.musicxml, .xml, or .mxl) from any notation app; .mxl is unpacked in the browser. For a scanned PDF, use the Audiveris workflow in omr/ first.
